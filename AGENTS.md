# Работа над AISpa

AISpa 1.0 — это Autopilot 2.2.0 Ника Велса (MIT) с правками владельца,
упором на бриф. Канон — навык `skills/aispa/SKILL.md` и файлы рядом с ним
(`phases/`, `prompts/`, `tools/ap.py`). Чем AISpa отличается от основы:
`docs/отличия-от-autopilot.md`. Доводы и замеры автора: `docs/design-autopilot.md`.
Состояние сборки и выпуска: `docs/status.md`.

Правило: меняй только то, что требует задача. Файлы основы берутся как есть;
не переписывай и не «улучшай» чужие тексты фаз для агента.

## Как проверять

- Один файл тестов, после каждой правки: `python3 tools/check.py --file tests/test_ap.py`
  (так же для остальных файлов в `tests/`).
- Полный набор: `python3 tools/check.py`. Он идёт один раз, на итоговой
  версии, перед выпуском; по ходу работы его не запускают.
- Один ручной CI (`.github/workflows/checks.yml`, область `full`) — только на
  итоговой версии и по решению владельца.

## Справочник ответов

`skills/aispa/references/support-faq.json` — канон ответов на вопросы
учеников, `docs/support-faq.md` получается из него генератором
`tools/render_support_faq.py`. Руками второй файл не правят. Ответ привязан к
файлам пакета; изменил такой файл — перечитай ответ и пересобери привязки и
документ (из корня репозитория; квитанция генератора нужна только для проверки,
поэтому — во временный файл):

```sh
python3 tools/render_support_faq.py --rebind --package skills/aispa --version 1.0.0 --output docs/support-faq.md --receipt "$(mktemp)"
```

Проверка, что канон свежий и `docs/support-faq.md` собран из него (первая
команда кладёт квитанцию во временный файл, вторая сверяет по ней документ),
и что установленный пакет отвечает:

```sh
r="$(mktemp)" && python3 tools/render_support_faq.py --package skills/aispa --version 1.0.0 --output "$(mktemp)" --receipt "$r" && python3 tools/render_support_faq.py --check --package skills/aispa --version 1.0.0 --output docs/support-faq.md --receipt "$r"
python3 skills/aispa/tools/aispa.py faq --version 1.0.0
```

## Публичный репозиторий

В файлы репозитория не попадают: имена и переписка учеников, токены и ключи,
пути рабочей машины, идентификаторы и папки прогонов, содержимое `.autopilot/`
и `.aispa/`. Цитаты и приватные источники живут только в папке прогона.
Тексты для учеников — по-русски, простыми словами, только про действующий
вариант.

## Выпуск

Слияние в `main`, тег, Release и обновление установок — только после «да»
владельца и по шагам `docs/release-1.0.0.md`. Одобрение сборки или проверок
выпуском не считается.
