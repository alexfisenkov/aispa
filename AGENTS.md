# Работа над AISpa

AISpa — самостоятельный навык разработки по брифу. Сейчас это
`0.1.0-alpha.2`, не стабильный выпуск и не готовый комплект для учеников.

## Источники истины

- `README.md` — фактический статус.
- `docs/decisions.md` — решения владельца и открытые вопросы.
- `docs/changes.md` — изменения, проверки и незавершённое.
- `skills/aispa/` — собственные инструкции и реализация.
- `tests/` — воспроизводимые проверки контрактов.

## Зоны

- `skills/aispa/tools/aispa_core/store.py` — файловые границы, журнал, снимки кода.
- `contracts.py` — схемы, полнота отчётов, контрольные суммы и свежесть проверок.
- `workflow.py` — правила переходов, задачи, волны и сдача результата.
- `display.py` — производное состояние для интерфейса; не принимает решения.
- `timing.py`, `progress.py` — отмеченные интервалы работы, этапы для экрана и приблизительная оценка времени.
- `skills/aispa/tools/aispa.py` — CLI, обработка ошибок и локальный HTTP-сервер.
- `skills/aispa/references/` и `prompts/` — контракт с агентом и проверяющими.
- `skills/aispa/assets/` — дашборд по предоставленному владельцем дизайну.
- `docs/` — публичная инженерная документация без личной переписки и доступов.
- Локальные скрытые архивы и результаты исследования исключены из Git.

## Ограничения текущего этапа

Владелец разрешил публичный репозиторий `alexfisenkov/aispa`, историю изменений
и GitHub Actions. Стабильный релиз только после его испытаний и отдельной
команды. Пока использовать только номер 0.x с обозначением alpha.

Пакет содержит собственные тексты, код и графику. Материалы локального
исследовательского архива не включать в исходники или публичную историю.
Не устанавливать рабочую альфу в пользовательские каталоги skills автоматически.
Для текущей работы владелец попросил самостоятельное исполнение без вызова
скиллов. Решения интервью записаны в `docs/decisions.md`.
Лицензия собственного кода — MIT с авторством Alexander Fisenkov.

## Проверки

Из корня: `python3 -m unittest discover -s tests -v`.
Интерфейс: `node --test tests/dashboard.test.cjs` (Node 18+, без npm-зависимостей).
До отправки проверить состав коммита, отсутствие секретов и локальных путей.
Промежуточные push не запускают Actions; один ручной запуск после целевого
локального набора проверок. Ошибка CI требует исправления и нового подтверждения.

Честно разделять проверку библиотечного кода, полный сценарий движка,
поведение LLM и пользовательское тестирование. Зелёные тесты не подтверждают
работу полного навыка, пока соответствующий сценарий не выполнен.
