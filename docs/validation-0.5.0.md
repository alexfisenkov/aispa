## Замер против автопилота и оси сравнения

Один маленький бриф (до 7 требований) и скрытый чек-лист закреплены SHA до
запусков; четыре запуска: Claude Code и Codex × AISpa и Autopilot, каждый в своём
временном репозитории с одинаковым стартовым деревом, безвопросные режимы,
одинаковая модель координатора и лимит 90 минут. Слепой судья видит результаты
под метками.

| Среда | Скилл | Время | Вопросы и остановки | Невыполненные пункты брифа | Токены |
|---|---|---|---|---|---|
| Claude Code | AISpa | | | | |
| Claude Code | Autopilot | | | | |
| Codex | AISpa | | | | |
| Codex | Autopilot | | | | |

Критерий «лучше автопилота»: AISpa не хуже по каждой оси в каждой среде —
соответствие брифу (обязательно), вопросы и остановки, время, токены там, где
среда их вернула. Каждая ось, где AISpa хуже, записывается здесь с цифрами
обеих сторон как невыполненная часть критерия и показывается владельцу до его
«да»: [впишет оркестратор].

Как считает `tools/measure.py`: весь вывод команды разбирается в памяти
целиком — предела нет; для прогона до 90 минут это допустимо. Сохраняемая
копия вывода обрезана до `MAX_STDOUT_BYTES` (4 МиБ), токены считаются по
полному выводу. Вопросы и остановки берутся только из файла событий, токены —
только из JSON среды, иначе «неизвестно».

## Приватность

Проверка 28.10.2026, тикет 14, на коммите ветки `32587f8` и рабочем дереве с
правками тикета 14 (до его коммита):

- Сборка `tools/package_update.py --commit HEAD` во временную папку: 134 файла
  пакета, ни одного пути `.aispa/`, `.autopilot/` и ни одного файла с
  перепиской или исследованием обращений.
- Строки, добавленные в ветку после `b914fad` (без `.aispa/` и `.autopilot/`):
  нет токенов вида `ghp_…`, `github_pat_…`, `sk-…`, нет ID прогонов этой машины,
  нет домашних путей вне тестов; в добавленных строках `.md` и `.json` нет ников
  вида `@имя`.
- Ники и имена авторов обращений из приватного исследования сверены с
  добавленными строками без вывода самих значений: имён — 0 совпадений; ник —
  одно совпадение, это имя владельца репозитория в адресе GitHub
  `alexfisenkov/aispa`, не ученик.
- В справочник, тесты и документы не добавлены имена, ники и цитаты учеников;
  позиция владельца о том, для каких задач нужна AISpa, передана пересказом.

Как повторить. Помощник проверки `privacy_check.py` хранится вне
репозитория, в служебной папке прогона оркестратора: он читает приватный
список ников и имён из исследования обращений, поэтому ни помощник, ни список
в репозиторий и пакет не попадают. Помощник печатает только числа и имена
файлов, совпавшие значения не выводит. Повтор — из корня рабочей копии на
финальном SHA, без незакоммиченных правок:

```bash
python3 -B <служебная папка прогона>/privacy_check.py . <файл приватного исследования> "$(mktemp -d)"
```

Проверка пройдена, если сборка пакета вернула 0, число путей `.aispa/`,
`.autopilot/` и файлов с перепиской — 0, токенов, ID прогонов и ников в
добавленных строках `.md` и `.json` — 0, домашних путей вне тестов — 0, а
совпадения ников из исследования — только имя владельца репозитория в адресе
`alexfisenkov/aispa`.

Повтор на финальном SHA перед PR: [впишет оркестратор].
