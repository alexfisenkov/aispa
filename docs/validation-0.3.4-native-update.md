# Короткая проверка обновления 0.3.3 → 0.3.4

Историческая проверка. Неуспешные клиентские попытки и непроверенные ветки
не закрыты последующей установкой файлов 0.3.5; [текущий статус](status.md).
Доступность клиентов заново не проверялась. Сохранённые ниже приватные пути
восстанавливаются по [описанию локальных архивов](local-archives.md).

23.10.2026. Две независимые временные копии опубликованного пакета 0.3.3;
исходный архив и все файлы сверены с manifest. До установки команды
`update-check` и `update-prepare` исполнял именно старый движок 0.3.3.

| Среда | Результат |
|---|---|
| Нативный субагент Codex | PASS: обнаружение, prepare, текстовое предложение двух вариантов, остановка до отдельного тестового согласия, apply, перечитывание SKILL, мини-продолжение и финальный current |
| Отдельный Codex CLI | BLOCKED до навыка: endpoint входа через ChatGPT отклонил настроенную модель, HTTP 400. Результат нативного субагента не считается PASS этого клиента |
| Claude Code | BLOCKED до команд навыка: провайдер вернул лимит сессии, HTTP 429. Повторных запросов к модели не делали |

Перед согласием root отдельно проверил неизменность старого пакета и отсутствие
продолжения. После согласия совпали 89 файлов 0.3.4 и сохранённый backup 0.3.3;
`smoke.py` завершился `SMOKE_OK`, исходный sentinel сохранён, появился
`CONTINUED.txt`, итоговый `update-check` вернул `current` с версией 0.3.4.
Выбор установки был отдельным сообщением тестового собеседника, не реальным
кликом владельца в графическом диалоге.

На Claude-копии root отдельно вызвал старый CLI: `available`, 0.3.3 → 0.3.4.
Это проверка движка, не подтверждение диалога Claude. Копия оставлена без
обновления для будущего повтора, когда модель станет доступна.

Все четыре основные установки побайтово неизменны. Код продукта, текущие
проекты и закреплённые runtime не менялись; полных прогонов проектов нет.
Не проверены ветка отказа от установки, графические кнопки выбора и работа
обновления через модель Claude. Следующий шаг — короткий повтор Claude после
восстановления доступности модели; новый релиз для этого теста не выпускался.

[Машиночитаемый итог](pilots/0.3.4/native-update-smoke.json). Сырые журналы и
копии сохранены приватно в `.проверки/native-update-034/` и временном каталоге;
личные пути и тексты нативных сессий в GitHub не публикуются.
