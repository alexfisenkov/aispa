# Установка AISpa

AISpa ставится из опубликованного выпуска (Release) на GitHub. Аккаунт GitHub,
токен и вход не нужны. Нужны Python 3.11 или новее и Git. На Windows
запускайте Python так: `py -3 -X utf8` или `python -X utf8`.

## Самый простой путь: попросить агента

Скопируйте запрос в своего агента, впишите среду и выберите, где ставить:

> Установи AISpa из последнего опубликованного стабильного Release для
> [название среды]. Где: только проект [путь к папке проекта] / все мои проекты.
> Сначала подготовь проверенный кандидат и покажи путь и версию; установи после
> моего «да».

**Только проект** — навык работает в одной папке. **Все мои проекты** — одна
общая установка для выбранной среды на этом компьютере. Если AISpa уже стоит
в выбранном месте, её не ставят поверх, а обновляют — [обновление](updates.md).

Файлы `install.py`, `aispa.zip` и `aispa-update.json` всегда берутся из одного
и того же выпуска, со страницы
[Releases](https://github.com/alexfisenkov/aispa/releases).

## Среды и папки установки

| Среда (`--runtime`) | Только проект | Все мои проекты |
|---|---|---|
| codex | `.agents/skills/aispa` | `~/.codex/skills/aispa` |
| claude-code | `.claude/skills/aispa` | `~/.claude/skills/aispa` |
| cursor | `.cursor/skills/aispa` | `~/.cursor/skills/aispa` |
| openclaw | `.agents/skills/aispa` | `~/.openclaw/skills/aispa` |
| gemini | `.gemini/skills/aispa` | `~/.gemini/skills/aispa` |
| antigravity | `.agents/skills/aispa` | `~/.gemini/config/skills/aispa` |

Папки «только проект» отсчитываются от `--project-root`. Любую другую свободную
папку можно задать абсолютным `--destination` вместо среды и области; тогда
установщик не выбирает среду за вас.

**Агенты Claude Code.** Для `claude-code` рядом с навыком ставятся шесть агентов
`aispa-*.md`: в `<проект>/.claude/agents` при установке в проект и в
`~/.claude/agents` при общей установке. Файл с тем же именем, который уже есть
и отличается, не перезаписывается: установщик называет его в ответе. Остальные
среды агентских файлов не получают.

## Два шага: просмотр и установка

Из папки со скачанным `install.py`:

```text
python3 install.py preview --runtime claude-code --scope project --project-root <путь-к-папке-проекта>
python3 install.py preview --runtime codex --scope global
```

Это варианты — выберите свою среду и область. Просмотр проверяет выпуск:
тег и commit, `aispa-update.json`, SHA-256 архива, состав, размеры и права
файлов. Проверку делает модуль обновления из того же commit выпуска. Кандидат
сохраняется в `~/.aispa-installs/` (или в `--cache-dir`); папка установки
ещё не создаётся. В ответе — `candidateId`, `destination`, `runtime`,
`version`, `commit`, `releaseUrl`, `archiveSha256` и список агентов.

После «да»:

```text
python3 install.py apply --candidate <candidateId> --confirm
```

Если при просмотре был свой `--cache-dir`, передайте его и сюда. Установка
ещё раз сверяет кандидата, не трогает уже существующую папку и отказывается,
если кандидат изменился после просмотра. Установщик отклоняет пакет, в котором
выбранная среда не объявлена.

Конкретный выпуск: добавьте к просмотру `--tag v1.0.0`. Подходит только
опубликованный Release; ветка, черновик или голый тег Git не подходят.

Время на подготовку — один общий запас, по умолчанию 30 секунд, не больше 120:
`--timeout 120`. Если запас кончился, незаконченный кандидат удаляется, папка
установки остаётся свободной — повторите просмотр.

Если GitHub ответит, что временно ограничил запросы без входа, установщик так
и скажет: аккаунт и токен не нужны, попробуйте через час.

## Запуск

Откройте новую сессию агента в папке проекта.

- **Claude Code:** `/aispa что нужно построить` или `/aispa путь/к/brief.md`.
- **Codex:** `$aispa что нужно построить`.
- Вызов без задачи продолжает прерванную сборку этого проекта.
- В остальных средах навык вызывают так, как эта среда вызывает установленные
  навыки.

Сама AISpa не запускается: только по вашему вызову.

## Несколько проектов

Каждую сборку запускайте из корня своего проекта. Её записи лежат в папке
`.aispa-work/` этого проекта и коммитятся вместе с ним. Общая установка навыка
не объединяет проекты и их историю. Параллельные проекты делят память,
процессор и лимиты среды.

## Проекты, начатые в прежней версии AISpa

Если в проекте есть папка `.aispa/` с незаконченной сборкой, AISpa продолжает
её той копией, с которой сборка начиналась и которая лежит внутри самой сборки.
Установка и обновление навыка эту копию не меняют. Новую сборку в таком проекте
AISpa не начинает, пока вы не скажете «закончи старую» или «начни новую».
