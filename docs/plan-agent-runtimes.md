# Поддержка OpenClaw, Gemini и Antigravity

Задание владельца от 22.10.2026: добавить полноценные адаптеры трёх сред,
вести изменения в GitHub, не запускать новые полные модельные прогоны.
Рабочая версия — **0.3.0, не опубликована**; текущий Release — 0.2.0.

## Обязательный объём

1. Все CLI-входы с runtime принимают шесть явных ID. ОС и модель не выбирают
   runtime автоматически; существующие контракты Codex/Claude Code/Cursor сохраняются.
2. Установщик выбирает подтверждённые project/global пути; остаётся самостоятельным,
   работает через опубликованный Release, preview/apply и проверку manifest.
3. Bootstrap сохраняет AGENTS.md, добавляет GEMINI.md для Gemini/Antigravity и
   точное always_on правило Antigravity. OpenClaw получает ссылку в AGENTS.md
   физического проекта; внешний workspace, аккаунты и права не изменяются.
4. Правила учитываются как общие входы: изменение снимает свежесть доказательств,
   запись требует зависимости с читающими задачами. Hidden allowlist ограничен Markdown-правилами;
   настройки с возможными секретами не становятся автоматически источниками.
5. Участники используют настоящие native ID/session; независимость, условный
   второй круг и финальная приёмка сохраняются по закреплённой политике.
6. Usage использует существующую проверяемую схему. Неизвестные счётчики и
   отсутствие независимых контекстов не превращаются в фиктивный PASS.
7. Новый движок не мигрирует активные 0.2.0. Завершённая история 0.2.0 доступна
   только для read-only handoff; новый заказ создаёт новый прогон.

## Выполнение

- Исследование: официальные спецификации и установленный код host; точные
  источники и ограничения в [адаптерах](../skills/aispa/references/native-agents.md).
- Код: общий список CLI-сред, project_context, installer, защита классов задач,
  общие входы, безопасное исследование, совместимость версии.
- Проверки: адресные CLI и библиотечные тесты, сохранение правил/backup,
  Unicode-пути, конфликты и symlink/junction guards, usage и старые журналы.
- Независимый разбор кода и соответствия заданию; повтор только при замечаниях.
- GitHub: ветка и коммиты, одна финальная матрица runtimes на Windows/macOS/Linux
  с Python 3.11/3.13. Полный прежний CI-профиль остаётся доступным по умолчанию.

## Границы

Нативный запуск субагентов и качество конечного проекта не проверяются этой
итерацией. Инженерный PASS не заменяет модельную приёмку. Новый Release и
установка рабочего кандидата пользователям не выполняются. Отдельный
Antigravity CLI имеет другой каталог; нативная совместимость его инструментария
не заявляется по наблюдениям приложения/IDE.

Результаты и открытые ограничения — [протокол](validation-agent-runtimes.md).
