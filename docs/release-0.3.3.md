# AISpa 0.3.3

Реализация и актуальность проверки теперь показаны отдельно:

- Завершённая задача остаётся «Реализовано». Ниже — «Проверка актуальна» либо
  «Проверку нужно обновить».
- Требования показывают сохранённую реализацию и отдельный статус проверки;
  частично выполненное требование не становится полностью реализованным.
- В волне отдельно считаются реализованные и актуально проверенные задачи.
  Полоса показывает реализацию, а её подпись не обещает приёмку.
- Фильтр «Требуют внимания» включает незавершённое и устаревшие проверки.
- Исторические и недоступные снимки сохраняют свои оговорки; выполняемая задача
  с устаревшей проверкой не называется реализованной.

Изменены подписи и отображение; правила приёмки, статусы журнала и проверки
не ослаблены. Для обновления панели начатого проекта используется refresh-view,
без изменения его закреплённого движка. Новых полных модельных прогонов нет.
[Проверки и доставка](validation-0.3.3.md).
