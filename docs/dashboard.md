# Дашборд AISpa

С alpha.2 используется дизайн владельца из архива дашборда: Chrome & Graphite,
шрифты Unbounded, Onest и JetBrains Mono, графитовые карточки и хромовые акценты.
Файл для дальнейших изменений — `skills/aispa/assets/dashboard.html`.
Он самодостаточен, кроме необязательной загрузки шрифтов Google Fonts.

## Источник данных

Локальный сервер отвечает на `/status.json` свежим представлением журнала.
Чтение не ждёт блокировку длительной команды verify и не изменяет журнал.
Каждый HTTP-запрос использует отдельный экземпляр читателя; повреждённое
или неполное состояние даёт 409. Сервер не возвращает прежний успех вместо
ошибки. На диске `status.json` остаётся снимком последней команды CLI.

Интерфейс запрашивает состояние каждые пять секунд, часы обновляет раз в
секунду. Через 15 секунд без подтверждённого ответа снимаются успешный
заголовок и положительные отметки проверок; остаётся явно подписанный снимок.
Фильтры не могут вернуть старое «принято». Таймеры фиксируются на последней
подтверждённой отметке. Успешный ответ восстанавливает отображение.

| Поле | Значение |
|---|---|
| `title`, `stage` | название и этап движка |
| `displayStage` | один из семи шагов интерфейса, выведенный из источников и проверок |
| `status`, `label` | результат, определённый движком |
| `gates` | актуальность покрытия, плана и приёмки |
| `requirements` | ядро, исходные требования, добавления, родитель и решение владельца |
| `tasks` | задачи, волны, состояние, отметки времени и длительность на observedAt |
| `remaining.checks` | неуспешные условия текущей приёмки |
| `remaining.blockedTasks` | ID актуально заблокированных задач, даже до финала |
| `remaining.excluded` | ID требований, исключённых по записанному решению владельца |
| `remaining.unmapped` | пункты исходного брифа, не попавшие в реестр |
| `remainingAssessed` | есть ли текущий отчёт приёмки; отсутствие отчёта не означает отсутствие остатков |
| `activity` | выполняющаяся команда проверки, видимая до её завершения |
| `elapsedSeconds` | накопленное время прогона без отмеченных пауз |
| `estimate` | примерный диапазон оставшегося времени либо причина отсутствия оценки |
| `decisions` | решения агента |
| `updatedAt`, `observedAt` | последняя запись и последняя проверка актуальности |

## Время

Команда start записывает startedAt и activeSince задачи. complete и block
останавливают текущий интервал. Пауза всего прогона останавливает его часы и
часы активных задач; resume запускает их снова. Reset и повторная попытка
сохраняют уже потраченное время по этому ID. Время включает ожидание инструментов
и простой, который не был отмечен паузой; это не CPU-время и не токены.

Для задач без записанного времени показывается «Время не записано». Длительность
не восстанавливается из времени изменения случайного файла.

После двух завершённых задач с измеренными длительностями берётся их медиана.
Нижняя оценка учитывает параллельные задачи одной волны, верхняя — возможное
последовательное исполнение. Добавляются запас неопределённости и резерв на
итоговую приёмку. Это ориентир, не обещание срока. Если задача превысила медиану,
её остаток не становится нулём автоматически. Блокер, пауза, недостаток данных
и итоговая проверка без известных сроков показываются словами вместо числа.

## Правдивость интерфейса

- `accepted` — приняты все действующие требования без остатков.
- `delivered_with_remaining` — ядро принято, остатки перечислены.
- `stale` — результат изменён, требуется новая проверка.
- `blocked`, `paused`, `cancelled` и потеря связи не выглядят как успешная сдача.
- «Реализовано по задачам» не означает «принято»; процента общей готовности нет.
- Пользовательские строки вставляются через textContent.
- `?demo` явно включает пример. `?status=accepted` без `demo` не влияет на живые
  данные. Демонстрационные таймеры и ETA подписаны как пример.

В новых прогонах используется alpha.2. Уже начатые прогоны продолжаются своей
закреплённой копией runtime: эта поставка не меняет их шаблон и часы задним числом.
