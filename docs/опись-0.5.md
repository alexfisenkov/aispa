# Опись движка AISpa 0.5: что уходит из ветки и как вернуть

Служебный документ для владельца. Опись посчитана по тегу `aispa-0.5.0-engine`, а не переписана из спецификации. Здесь ничего не удаляется: файлы убирает отдельный шаг сборки, и только по блоку `опись:удалить` ниже.

## Порядок и условия

- Список показывается владельцу до слияния в `main`.
- В `main` ничего не удаляется до его приёмки на живом материале.
- Путь отката: тег `aispa-0.5.0-engine` и выпуск `v0.4.0` (проверено ниже). Тег не создаётся и не двигается.
- Незаконченные прогоны учеников работают на своих закреплённых копиях пакета в их проектах, поэтому удаление из ветки их не задевает.
- Спорные пути решает владелец до слияния: пока ответа нет, они остаются в ветке.

## Путь отката

```
git rev-parse 'aispa-0.5.0-engine^{commit}'   # 434dac7f4cf840ba5b083a3cec15c0dc8bf528e6
git rev-parse 'v0.4.0^{commit}'               # 0977f893106312a87068fb6533e03f1ca9ad8633
```

Обе команды выполнены при составлении описи, результаты совпали с записанными выше.

## Проверка, что из списка ничего не осталось

Команда из корня репозитория печатает пути из блока, которые ещё есть в рабочем дереве, и в последней строке их число. До удаления число равно размеру блока; после удаления должно быть `0`.

```
awk '/^```опись:удалить/{f=1;next} /^```/{f=0} f' docs/опись-0.5.md | while IFS= read -r p; do [ -e "$p" ] && echo "$p"; done | awk '{print} END{print NR}'
```

Те же числа можно пересчитать по тегу командой `git ls-tree -r -l aispa-0.5.0-engine` (размер в четвёртом столбце).
