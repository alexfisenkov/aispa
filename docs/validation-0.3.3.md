# Проверки AISpa 0.3.3

Кандидат. Область — подписи/представление dashboard.html и совместимость
чтения завершённой/активной 0.3.2 после повышения версии пакета.

Инварианты: completed в журнале не сбрасывается; proofCurrent, phaseStale,
gates, acceptance и значения backend не меняются. Реализация выводится из
записанного completed, а актуальная проверка — из отдельного доказательства.
Running+stale и частичное выполнение не объявляются завершёнными. Архив и
потеря связи не объявляются текущим PASS. Полных модельных прогонов нет.

Локально: 69 Node и 2 Python PASS, команды и exit codes сохранены в
[квитанции](pilots/0.3.3/verification.json). Проверены completed/stale, running/stale,
частичные требования, устаревшая итоговая приёмка, переключение фильтра,
архив/потеря связи, RU/EN и сохранность исходного объекта данных.
Совместимый viewer читает активную 0.3.2; обычный writer её не мигрирует.

Синтетический IAB показал «Реализовано / Проверку нужно обновить» и отдельные
счётчики 1/1 и 0/1. [AX](pilots/0.3.3/preview.txt), [снимок](pilots/0.3.3/preview.png).
Два прицельных круга tech/reality: учтён stale acceptance в фильтре и убрана
неподтверждённая причина устаревания из подписи; финальные вердикты OK.
