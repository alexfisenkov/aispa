# Проверка alpha.2 · 19.10.2026

Проверена интеграция дизайна владельца с текущим состоянием AISpa, новые
часы задач и прогона и приблизительный диапазон оставшегося времени.

## Локальные результаты

- 61 тест Python прошёл, включая сквозной CLI, паузу и повторные попытки,
  оценку по волнам и чтение HTTP-состояния во время длительной проверки кода.
- 15 тестов доставляемого inline-JS прошли: фильтры, таймеры, деморежим,
  корректные поля остатков, безопасный вывод текста, отсутствие ложного
  «принято» при ошибке связи или параметре предпросмотра.
- Во встроенном браузере проверен синтетический прогон настоящего движка:
  активная задача T02, рост времени, затем пауза. После обновления и смены
  фильтра время оставалось на 4 мин 24 с, заголовок — «Приостановлено».
- `?status=accepted` без деморежима не изменил состояние паузы.
- Для фиксированных viewport 320, 390 и 1280 CSS px ширина документа совпала
  с scrollWidth. Горизонтального переполнения страницы не обнаружено.
- Фильтр ядра на тестовом прогоне показал только R01. На демонстрационном
  примере проверена компоновка текущей работы, диапазона ETA и волн.

Скриншоты и полные локальные логи хранятся в исключённом из Git каталоге
проверок. Публичный результат GitHub Actions привязан к SHA поставки в
разделе Actions репозитория; промежуточные push не запускают CI.

## Пределы подтверждения

Фиксированные viewport проверялись в браузере, не на физическом телефоне.
Модель не выполняла реальный большой проект во время этой проверки: данные
прогона синтетические. Точность ETA на длительных реальных проектах ещё
нужно измерить. Диапазон в дашборде является ориентиром, а не обещанием срока.

Установленные навыки и закреплённые runtime уже начатых прогонов не обновлялись.
Эта поставка не является стабильным релизом.
