# Изменения и проверки

## 19.10.2026 — начало разработки

Создан публичный репозиторий и собственная реализация AISpa. Первый коммит
содержал хранилище и 12 его проверок. После трёх раундов интервью реализованы
контракт требований, обязательное ядро, зависимые задачи, волны, проверка
текущего кода и итоговая приёмка с возможными второстепенными остатками.

Добавлены неизменные снимки брифов, точные цитаты, журнал с контрольной
цепочкой, запрет повторного ID требования, отказы на неполных доказательствах,
устаревание проверок и закреплённая копия движка для продолжения прогона.
Сброс задачи сбрасывает её зависимые задачи; новая редакция задачи не
сохраняет прежнюю отметку завершения.

Собственные инструкции и форматы описаны для трёх сред. Создан временный
HTML-экран без финального оформления; пользовательский текст вставляется
через textContent. Сервер пересчитывает свежесть при запросе состояния,
а при ошибке не возвращает старую положительную приёмку. Визуальную часть
дальше меняет владелец.

Проверки в `tests/` охватывают хранение, отрицательные переходы, полный
синтетический проход CLI отдельными процессами и локальный HTTP-сервер.
GitHub Actions запускается вручную; актуальный результат — в Actions
репозитория для соответствующего commit SHA.

Локальный итог этой итерации: 48 тестов прошли на macOS, полный сценарий CLI
выполнен, JavaScript временного экрана прошёл синтаксическую проверку Node.
Дополнительно проверены 15 локальных Markdown-ссылок и состав 27 публичных
файлов; исследовательские архивы и локальные пути в поставку не входят.

Модельные прогоны и пользовательская приёмка ещё не выполнены. Открытое и
план испытаний — [testing.md](testing.md). Релиз 1.0 не объявлен.
