# Изменения

Журнал изменений AISpa. Записи датированы и не переписываются: новые
добавляются сверху. История самого Autopilot — в репозитории его автора,
github.com/nick-vels/skills. Состояние проверок и выпуска — [статус](status.md).

## 28.10.2026 — 1.0.0

Основа — Autopilot 2.2.0 Ника Велса (коммит `25b5fba`, MIT), взятый как есть,
с правками владельца. Полный перечень по файлам:
[отличия от Autopilot](отличия-от-autopilot.md). Группы правок:

- **Бриф.** Заказанный способ записывается отдельной строкой и не подменяется ни
  в описании, ни в шаге, ни у исполнителя, ни у проверяющего; каждый ответ
  человека попадает в бриф; снять требование можно только его словами;
  расхождение на слепой приёмке чинится и проверяется заново.
- **Модели.** Одна таблица ролей для Claude Code и Codex, шесть готовых агентов
  Claude Code, явный маршрут в Codex; ничего выше Opus · high и Sol · high.
- **Непрерывность.** Вызов без задачи продолжает прерванную сборку; панель во
  встроенном браузере Codex; исполнителей волны ждут в том же ходе; выключенные
  субагенты — остановка с понятной подсказкой.
- **Честное время.** Диапазон остатка по истории прогонов, «пока не знаю» без
  замеров, «идёт дольше обычного»; `tools/eta-honesty.cjs` проверяет попадание.
- **Слова и поставка.** Имя AISpa, рабочая папка `.aispa-work/`, русские слова
  для человека, установщик и обновление без аккаунта GitHub, справочник
  ответов с генератором, один полный набор проверок на трёх системах (запуск
  вручную), протокол выпуска [release-1.0.0.md](release-1.0.0.md).
- **Авторство.** `LICENSE` с двумя уведомлениями, шапки в `ap.py` и шаблоне
  панели, доводы и замеры автора в [design-autopilot.md](design-autopilot.md)
  и [benchmark-autopilot.md](benchmark-autopilot.md).
