# Изменения и проверки

## 19.10.2026 — начало разработки

Создан отдельный проект AISpa. Начата собственная реализация хранения
истории, неизменных источников и контрольных сумм кода. Команда исполнения
навыка и весь путь от брифа до приёмки пока не готовы.

Проверки хранилища находятся в `tests/`. Их успешный результат подтверждает
только проверенные операции хранилища. Пользовательские сценарии навыка и
работа разных LLM ещё не проверены.

Следующие работы: закончить интервью, реализовать согласованные переходы,
добавить негативные и сквозные тесты, выполнить GitHub Actions. Дашборд —
отдельная работа владельца. Ограничения текущего ядра: Git submodules пока
не поддерживаются; повреждённый журнал автоматически не исправляется.
