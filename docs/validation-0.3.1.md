## Видимый браузер

22.10.2026 создан синтетический init «AISpa · проверка открытия панели».
Init вернул start-and-open-dashboard; start — open-dashboard с проверенным
loopback URL. Open-in-Codex вернул queued: это не засчитано как открытие.
Доступный CUA createBrowserTab(iab, url, {visible: true}) открыл видимую вкладку.
Read-back и скриншот показали 0.3.1, название фикстуры, «Живые данные · локальный
сервер», этап «Бриф» и обновляющийся таймер. Вкладка сохранена markDeliverable.
Это проверка UI/CLI, не полный модельный прогон проекта.

## Контракт и границы

Init/resume не запускают процессы сами: они возвращают обязательное действие
host. Dashboard start проверяет собственную службу и требует открыть UI.
Наличие поля не заставляет произвольную модель безошибочно следовать инструкции.
Видимость в остальных приложениях и Windows UI этой проверкой не подтверждены.

Полные модельные прогоны и повторы референса: 0.

## Независимая критика

Два прицельных круга: техника и доказательства. Исправлены список запретов
batch, таблица новых полей, различие pending/assigned и отдельные UI-квитанции.
Read-only критики не выдаются за собственный запуск тестов или публикацию.
Результаты нативного UI основного агента подтверждаются AX и изображениями.
