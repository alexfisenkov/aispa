Хранилище проверило read-only handoff alpha.10 для accepted,
delivered_with_remaining и cancelled, отказ работы с активной чужой версией
и неизменность старого журнала при новом init. Первая установка проверила
stable default, mixed higher prerelease/stable, явный опубликованный tag,
draft/unpublished, булев флаг GitHub и понятный отказ без stable.

Изолированный переход alpha.10 → 0.1.0 подготовлен и применён, затем выполнен откат:
байты и режимы файлов восстановлены, новая копия сохранена, pinned runtime
и активный журнал остались неизменными. Стабильный пакет воспроизводимо собран
из точного Git commit тестовой фикстуры; ZIP, manifest и installer совпали
между двумя сборками и прошли prepare/apply/rollback.

GitHub-транспорт в этих тестах подменён. Это проверки механизма, а не скачивание
опубликованной 0.1.0. Они не заменяют полный набор на финальном release commit.

## Локальный кандидат и независимая проверка

До исправлений критики полный локальный набор: 679 Python-проверок,
659 PASS и 20 OS-specific skips, 338.026 с. Панель: 39/39 Node; пример
study-plan: 15/15. Локальный браузер с синтетическим light payload показал
0.1.0, «Выполнение проверено» и неподтверждённую общую приёмку; это smoke
интерфейса, а не модельный прогон.

Два независимых критика в первом круге нашли ошибки границ: повышение не
позволяло расширить зону; удаление heavy могло оставить только light-покрытие;
известные prompt-пути проходили как документы; устаревшие completed peers
исключались из проверки границ. Исправлены также противоречия инструкций и
оценки ролей. Второй адресный круг critic-code и critic-skeptic — PASS.
После исправлений прошли 28 адресных регрессий (15.761 с). Позже writer
воспроизвёл обход через cardHistory, исправил его; координатор перечитал guard,
два адресных теста прошли (0.889 с). Третьего круга критиков не было.

## Не проверяется этой итерацией

- Новые полные модельные прогоны и новый парный тест с референсом: не проводятся
  по решению владельца. Экономия токенов и преимущество качества не измерены.
- Все пользовательские конфигурации Codex, Claude Code, Cursor и Windows-host:
  локальные тесты и CI не заменяют их отдельную приёмку.
- Изменение глобальных установок: не выполняется. Старые активные runtime и
  исторические отчёты не переписываются.

Число ролей, байты контекста и `verified_completion` не являются измерением
токенов, модельным PASS или итоговой приёмкой проекта. Сохраняющиеся ограничения
и пользовательская матрица — [testing.md](testing.md).
