# Проверки AISpa 0.4.0

24.10.2026 владелец разрешил закрыть issue №12, выпустить обновление после
проверок и обновить локальные установки всех своих агентов.
Стабильный выпуск опубликован, четыре установки обновлены. Полных модельных
проектов не запускали; активные закреплённые runtime не менялись.

## Адресные проверки

Локально подтверждены **383 разные Python-проверки и 84 Node-проверки**.
Первый составной запуск из cwd=tests дал 347 PASS и одну ошибку загрузки
существующего test_display_details: не находился пакет tests. Это ошибка
команды запуска, а не исправление кода; отдельный запуск из корня с
PYTHONPATH=tests прошёл 11/11. После замечаний ревью повторены только
затронутые формы/режимы/отчёты — 46/46. Исходный неуспешный запуск сохранён;
[квитанция с SHA логов и подсчётом уникальных проверок](pilots/0.4.0/local-verification.json).

- Матрица 57 критериев (5 automated / 46 browser / 6 process) проверяет
  полноту списка, разделение маршрутов, RED/GREEN и summary. Это не 46
  фактически выполненных браузерных наблюдений.
- Отдельная Git-фикстура с настоящими subprocess-командами и синтетическими
  browser/process JSON прошла RED/GREEN → submit → nonPASS → repair →
  critic2 → acceptor → wave → общая приёмка. Неполная итоговая проверка брифа
  отвергнута. Карточки, участники и попытка сохранены; новый журнал не создавался.
- Отрицательные случаи: отсутствующий/повторный/чужой критерий и способ,
  неверный policy, чужая попытка/candidate/intent SHA, устаревшие и подменённые
  наблюдения/приложения, попытка убрать автоматическую проверку или изменить
  маршрут после сдачи/критики. Исторические доказательства также перечитываются.
- Fast без контракта сохраняет прежний облегчённый путь; явно записанный
  контракт новой политики обязателен и не отображается как пропущенный RED.
- Новая форма отказных проверок доступна до первого intent командой
  template failure-checks --mode mixed. Legacy-форма сохранена; CLI проверяет
  policy, флаги и отсутствие записи в журнал.

## Интерфейс и независимая проверка

Шаблоны остаются not_tested. Адресный контекст сохраняет исходные ссылки,
критерии и trace; дополнительные формы не создают PASS.
В IAB открыт синтетический demo с тремя типами: RU-подписи просмотрены на
раскрытой карточке, EN-подписи проверены через accessibility tree.
[Снимок](previews/mixed-evidence/ru.png),
[границы UI-проверки](previews/mixed-evidence/verification.json).
Отдельный мобильный viewport и пользовательский проект этим не проверялись.

Независимые tech/evidence обзоры — OK после адресного второго раунда.
Закрыты несоответствия fast/skipped RED и старых форм/инструкций.
[Квитанция ревью](pilots/0.4.0/review.json).

Четыре независимые установки обновлены **0.3.5 → 0.4.0** штатным старым CLI:

Перед применением сверены commit/manifest/ZIP/93 файла, после — весь пакет
и резервная копия исходной 0.3.5. Все новые CLI отвечают current.

[Read-back каталогов](pilots/0.4.0/native-discovery.json).

не проверялось. Новая политика относится к новым init, активные проекты
сохраняют прежние закреплённые runtime.

## Первая CI и адресная проверка исправления

[Полная адресная матрица](https://github.com/alexfisenkov/aispa/actions/runs/40077364126)
прошла на Linux/macOS. Оба Windows-job завершили по 383 проверки: 382 PASS и одна
ошибка UTF-8 чтения JSON в новой тестовой фикстуре. В helper добавлен явный
encoding="utf-8"; продуктовый код не изменён. Прежний результат сохранён в
[квитанции](pilots/0.4.0/ci-first-attempt.json). Успешная повторная CI ограничена mixed,
отказными формами и отображением режимов; общий набор без основания не повторялся.
