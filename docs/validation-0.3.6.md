# Проверки AISpa 0.3.6

24.10.2026: владелец передал дефект из рабочего UX-прототипа для исправления
и выпуска. Исходные пользовательские тексты и журнал в публичный репозиторий
не включаются. Состояние выпуска пока — кандидат.

## Дефект и область изменения

Регистрация требований принимала полную цитату, а сценарии одновременно
требовали её точного совпадения и длины не более 1600 символов. Исправлен
только этот конфликт. Соседние лимиты в ideas и specQuote относятся к
выбираемым фрагментам; общий предел отчёта сохраняется.

До исправления новый тест воспроизвёл четыре отказа: длины 1601/4096 для
requested и addition; граница 1600 проходила. После исправления 12 тестов
design_contract прошли, включая отрицательные сценарии, точную границу
размера JSON, неверный ключ path вместо file и сохранение прежних лимитов.

Отдельно текущий валидатор прочитал исходный отчёт заблокированного проекта:
31 функция, три зарегистрированные цитаты по 2422 символа. Отчёт принят;
изменённая цитата и устаревший basis отвергнуты. SHA журнала до/после чтения
совпал. Это проверка валидатора, не возобновление рабочего проекта.
[Обезличенная квитанция](pilots/0.3.6/source-reproduction.json).

## Адресный ремонт

Реализованы отдельная исправленная копия точного runtime 0.3.5, явное
подтверждение с файлом согласия и append-only событие с прежним/новым digest.
20 синтетических тестов прошли: настоящий CLI старого пакета отклоняет длинную
цитату, возвращённый исправленный CLI сохраняет её дословно. Проверены
префикс прежнего журнала, источники, состояние, разрешённая ручная заплатка,
CAS, отказ без подтверждения, повтор, ссылки и сбой до записи события.
Осмотр реального заблокированного проекта без записи также прошёл: 108
артефактов прогона проверены; одна внешняя ссылка не проверялась на актуальность.
Действующий проект, его код, оригинальный runtime и журнал этой задачей
не изменяются. Применение ремонта выполняет агент, ведущий тот проект.
