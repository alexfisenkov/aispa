# Статус AISpa 1.0

Сверено 28.10.2026. Реализация, результаты отдельных проверок, итоговая
приёмка и выпуск — разные вещи; ниже они разделены.

## Сделано (реализация в ветке `work/aispa-1.0`)

- Основа — Autopilot 2.2.0 (коммит `25b5fba`), правки владельца по файлам:
  [отличия от Autopilot](отличия-от-autopilot.md).
- Бриф, модели, непрерывность, честное время, имя и слова для человека,
  установщик и обновление, справочник ответов, инструмент замера сравнения с
  Autopilot, опись и удаление прежнего движка из ветки.
- Документы: [README](../README.md), [установка](install.md),
  [обновление](updates.md), [справочник](support-faq.md),
  [нативная Windows](windows.md), [изменения](changes.md),
  [протокол выпуска](release-1.0.0.md).
- По ходу работы гонялись только тесты затронутых мест каждого шага.

## Не проверено

- Полный набор тестов на итоговой версии не запускался.
- Ручной CI на трёх системах не запускался.
- Слепая приёмка собранной AISpa по брифу сборки не проводилась.
- Замер сравнения с Autopilot (время, ввод, остановки, число вопросов,
  добавления сверх брифа; Claude Code и Codex, продолжение в новом чате) не
  проводился: цифр паритета пока нет.
- Установка из опубликованного выпуска не проверялась: выпуска 1.0.0 ещё нет.

## Ждёт владельца

- Приёмка итога сборки и его «да» на выпуск; без него слияние в `main`, тег,
  Release и обновление установок не делаются.
- Решение по шести спорным путям из [описи](опись-0.5.md): до ответа они
  остаются в ветке.
- Снятие флага автозапуска в личных копиях после выпуска, как записано в
  протоколе выпуска.

## Путь отката

Теги `v0.4.0` и `aispa-0.5.0-engine` и резервные копии установок; до приёмки
владельцем из `main` ничего не удаляется.
