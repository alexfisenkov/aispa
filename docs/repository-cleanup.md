# Обслуживание репозитория · 23.10.2026

Владелец поручил привести в порядок документы и служебные остатки после выпуска
0.3.5. Код продукта, версия, установленные навыки и существующие прогоны не меняются.
Новый релиз и полные модельные прогоны для уборки не нужны.

## Исходное состояние

Основное дерево и семь дополнительных worktrees были чистыми; main совпадал
с GitHub. Все вершины старых локальных и удалённых веток уже входили в main.
Stash, открытых PR и Issues не было. В `.проверки` находились 70 вложенных
тестовых репозиториев, из них 15 с локальными изменениями/неотслеживаемыми файлами.

## Сохранность

До удаления рабочих копий сохранены полное дерево, Git-история и исходные
GitHub-описания. Все файлы tar сверены с SHA-манифестом, bundle проверен Git.
Непосредственно перед уборкой повторно проверено совпадение удаляемых файлов
со снимком; процессов с cwd в старых worktrees не обнаружено.
[Архив и восстановление](local-archives.md).

- Сняты семь завершённых worktrees; их файлы доступны в проверенном архиве.
- Удалены 14 старых локальных и 13 удалённых служебных веток. Их вершины
  предварительно проверены на достижимость из опубликованного main;
  удалённые refs удалялись атомарно с проверкой ожидаемых SHA.
- Старые loose-каталоги `.проверки`, `.источники`, `документы` и производные
  кэши убраны после сверки с архивом. Архив исключён из Git через `.gitignore`.
- Исправлены устаревшие текущие статусы; исторические протоколы сохранены
  и снабжены ссылками на последующие результаты.
- Описание GitHub Release 0.2.0 больше не называет его неопубликованным;
  тег и ресурсы не менялись. Ссылки PR №9 переведены со снятой ветки на main.
- Проверены 295 относительных ссылок в 31 изменённом Markdown: отсутствующих
  целей нет. `git diff --check` и повторная проверка архива/bundle прошли.

  main `158377bb353093d1cd404742487a6f94f68c5558`. При документационной уборке

Заключительный контроль после слияния — чистота main, совпадение с GitHub,
