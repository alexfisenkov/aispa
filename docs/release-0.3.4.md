# AISpa 0.3.4

Исправлено обнаружение обновлений GitHub Releases:

- Пустая первая страница перепроверяется один раз; список дополнительно
  сверяется с отдельным адресом последнего опубликованного стабильного релиза.
- Устаревший непустой список тоже дополняется latest; версия выбирается по
  SemVer с сохранением stable/prerelease каналов.
- Первая установка по явному тегу проверяет конкретный опубликованный Release
  и не зависит от общего списка.
- Сетевой отказ и некорректные метаданные не выдаются за отсутствие обновлений.
  Обнаружение имеет общий тайм-аут и ограниченное число запросов.

Токен GitHub для проверки не нужен. Проверки архива, контрольных сумм,
происхождения, подтверждение установки и резервная копия сохраняются.
Активные проекты продолжают работать своим закреплённым движком.

Новых полных модельных прогонов нет. [Проверки и доставка](validation-0.3.4.md).
