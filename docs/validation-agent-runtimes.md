# Проверка адаптеров агентов · кандидат 0.3.0

Статус: реализация подготовлена; финальная CI и независимый разбор ещё не завершены.
Объём и ограничения — [план](plan-agent-runtimes.md). Полных модельных прогонов — 0.

## Локальная инженерная проверка

На macOS/Python 3.14 выбранный профиль regressions прошёл 357 тестов за
96.897 с: 345 PASS и 12 Windows-specific skips. Отдельный добавленный тест
переноса правил трёх новых сред в чистый клон — PASS. Всего охвачено 358 тестов,
а не полный набор проекта; подробный список модулей закреплён в
`.github/workflows/checks.yml`, профиль `runtimes`.

Подтверждены:

- init/context/participant/knowledge и маршрут assign всех шести сред;
- project/global destinations, preview/apply, отказ перезаписи и обновления;
- сохранение пользовательских правил, backup, повторный init, refresh без
  изменения правил, конфликт файла-каталога и symlink guards;
- изменение правил снимает свежесть task fingerprints, запись общих правил
  требует зависимости, скрытые настройки не попадают в discovery автоматически;
- учёт заявленных actor IDs на синтетических данных, сохранение unknown usage, отказ дублей/чужого runtime;
- активный 0.2.0 требует закреплённый runtime, завершённый допускает read-only handoff;
- чистый клон содержит публичные указатели и не зависит от приватной памяти.

После первого разбора повторены 87 затронутых тестов — PASS. После адресного
учёта `.agents/rules.json` — ещё 27 адресных тестов PASS. Дополнительные 60 тестов
CLI/blind/cleanroom сначала дали две ошибки импорта из-за запуска из `tests/`;
команда исправлена на корень проекта с `PYTHONPATH=tests`, оба упавших сценария
прошли повторно. Итоговый CI-профиль содержит 420 тестов; набор и квитанции
команд/exit code/хеши логов — [local-verification.json](pilots/runtime-support/local-verification.json).

Локальные ссылки изменённой документации: 155 проверены, отсутствующих — 0
([квитанция](pilots/runtime-support/local-verification.json)).
Один финальный CI на трёх ОС запускает этот профиль и smoke сервера дашборда;
полный CLI, blind, cleanroom и offline pip Windows включены.
Профиль `full` остаётся неизменным вариантом по умолчанию; модельные испытания
не входят ни в один из этих CI-профилей.

## Независимый разбор

| Линза | Круг 1 | Круг 2 | Решение |
|---|---|---|---|
| Техника | BLOCK | BLOCK: новый край `.agents/rules.json` | Все четыре подтверждённые находки исправлены; последнюю правку проверил основной агент адресными тестами, третьего круга нет |
| Факты | FIX | OK | Переписана инструкция установки, релизы и кандидат разделены |
| Доказательства | FIX | ожидает финальной CI | Добавлены адресные квитанции, сужены заявления о native execution |

Первый технический круг выявил свободную фразу вызова OpenClaw вместо явной
команды, установку старого несовместимого пакета в новый host и отсутствие
пользовательских rules в fingerprints. Теперь `/aispa` указан явно,
установщик читает RUNTIMES из проверенного ZIP при preview/apply, а правила
и их registry влияют на свежесть и зависимости.

Проверка чистой функции установленного OpenClaw подтвердила разбор `/aispa`
и `/skill aispa` без импорта приложения и обращения к провайдеру.
[Квитанция парсера](pilots/runtime-support/openclaw-parser.json). Это не вызов
навыка моделью и не проверка полной диспетчеризации приложения.

Существующий долг вне этой итерации: body опубликованного Release 0.2.0 всё ещё
называет его кандидатом; GitHub API и ресурсы подтверждают публикацию. Текст
внешнего Release здесь не редактировался.

## Не подтверждается этими проверками

- Качество полного модельного проекта и экономия токенов в новых средах.
- Доступность native subagents/ID/прав во всех аккаунтах и версиях приложений.
- Рабочая сессия Antigravity CLI: это отдельная поверхность от app/IDE.
- Опубликованный Release 0.3.0 и установка в пользовательские каталоги.

Код адаптера, обнаружение SKILL.md, схема доказательства и выполнение модели —
разные уровни проверки; контракты приложений и их границы приведены в
[нативных адаптерах](../skills/aispa/references/native-agents.md).
