# Проверка alpha.3 · 19.10.2026

## Локальные воспроизводимые проверки

- macOS, Python 3.14: `python3 -B -m unittest discover -s tests -q` —
  133 теста, PASS. Сюда входят полный синтетический CLI-сценарий, журнал,
  две критики и приёмка, зависимости, контекст трёх сред и updater.
- `node --test tests/dashboard.test.cjs` — 17 тестов, PASS, включая названия
  текущего критика и повторную проверку устаревшего доказательства.
- `actionlint` — PASS для ручной CI и будущей упаковки опубликованного Release.
- Публичный состав проверен на секреты, личные пути и посторонний брендинг;
  локальные архивы, брифы и пилот исключены из Git. Проверены Markdown-ссылки
  и отсутствие ошибок whitespace.

Независимый обзор интеграции обнаружил и помог закрыть обходы: разные
написания одного пути в zones, удаление/возвращение требования под новым ID
задачи, повторное использование уже включённого брифа для новой попытки.
Добавлены регрессии. Ошибка обновления context после записи теперь явно
сообщает о сохранённом событии, чтобы не повторять уже выполненную операцию.

## Настоящий мини-пилот Codex

На предфинальной закреплённой сборке alpha.3 выполнена последовательность
четырёх настоящих отдельных нативных контекстов: worker → critic1 → critic2 →
acceptor. Их фактические идентификаторы записаны командой assign. Координатор
перенёс фактические выводы в отчёты движка; произвольные ID для этого пилота
не использовались. Пилот локальный и не содержит пользовательских данных.

Задача — небольшая функция нормализации имени по синтетическому брифу.
Исполнитель создал реализацию и 7 unittest-проверок. Оба свежих критика
независимо проверили Unicode, ошибочный ввод и работу без внешних зависимостей;
оба дали PASS. Второй критик запускался после первого PASS.

Отдельный приёмщик сначала прочитал полный исходный бриф и обнаружил
`Include unittest tests.`: тесты сделаны, но это предложение отсутствовало
в реестре требований и traceRequirements. Он вернул REJECT с unmapped.
Движок сохранил отказ: complete завершился с кодом 2, задача получила blocked,
попытка закрыта. Третий критик, сброс и новая попытка не запускались.

Это подтверждает конкретный сценарий обнаружения потерянного требования и
отказа после двух положительных проверок кода. Это **не** успешная сдача всего
навыка или пользовательского проекта. Охранные правки, добавленные после
закрепления пилота, проверены финальным автоматическим набором отдельно.
Исправление после FAIL первого критика проверено синтетическими тестами;
настоящий модельный сценарий repair остаётся в плане испытаний.

## Проверка GitHub Releases

Живой GitHub API подтвердил: опубликованных Releases пока 0. update-check
с системным доверенным CA bundle вернул no_release, alpha.3 и запрет установки
поверх Git checkout. TLS-проверка не отключалась. Без указания системного
bundle текущая локальная установка Python дала CERTIFICATE_VERIFY_FAILED;
updater вернул offline и не менял пакет. Настройки Python не изменялись.

Сборщик архива проверен тестом на повторяемость, точный Git commit и одинаковые
копии LICENSE. Ресурсы финального commit дополнительно собираются локально до
push. Release workflow проверен статически; его настоящая загрузка ресурсов
не запускалась, поскольку владелец ещё не поручал публиковать Release.

## Границы подтверждения

- CI относится к конкретному commit в GitHub Actions; успешный локальный
  запуск не заменяет результат CI. История запусков доступна в репозитории.
- Нативные прогоны Claude Code и Cursor не выполнены; их файловые адаптеры
  проверены тестами. Полный многоволновой проект и восстановление модельного
  контекста во всех средах требуют пользовательских испытаний.
- Установка и откат из настоящего опубликованного Release пока не испытаны.
  Синтетические тесты транспорта/архивов/CAS/rollback прошли; реальные ресурсы
  появятся после отдельной команды владельца на выпуск.
- В этой итерации интерфейс проверен JS-тестами; новый визуальный прогон
  браузера не выполнялся. Базовый дизайн проверялся в alpha.2.
- Навык не установлен глобально; активные пользовательские прогоны не менялись.
