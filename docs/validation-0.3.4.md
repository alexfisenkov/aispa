# Проверки AISpa 0.3.4

Задача: устранить ложное отсутствие опубликованных обновлений. Полные
модельные прогоны не проводились и не запланированы.

## Установлено до правки

При выпуске 0.3.3 были зафиксированы пустые ответы общего списка при доступном
конкретном Release. Точная причина непостоянства ответов не установлена.
Новый checker до публикации без авторизации обнаружил v0.3.3 для установленной
0.3.3. Квитанция и сырые ответы — `.проверки/release-discovery/live-discovery-receipt.json`
и связанные `public-response-*.json` (локально). Единичная успешная проверка
не опровергает прошлый сбой.

## Адресные проверки

Локально: updater — 41 тест PASS, включая пустую и устаревшую выдачу,
SemVer/каналы, malformed latest, HTTP 403/429/500, общий deadline,
prepare/apply/rollback, неизменность пакета при check и защиту архивов.
Установщик: 26 тестов PASS, включая прямой опубликованный тег без списка,
перепроверку пустой страницы, latest, HTTP-ошибки, общий бюджет обнаружения,
CLI preview/apply и файловые guards. Совместный целевой набор: 77 тестов, OK, 3 пропуска нативных Windows junction
на macOS. Его журнал:
`.проверки/release-discovery/local-tests.log` и `local-tests-receipt.json`
с командой, подтверждённым exit code и SHA исходников (локальные, не в Git).
Независимый review: tech — OK в первом круге; reality — OK во втором
после уточнения квитанций и сужения сетевого утверждения до сохранённых ответов.
Код после review не менялся. Финальная CI, публикация 0.3.4 и установка
пока не подтверждены.

## Границы

Latest не содержит prerelease; если обе страницы списка скрывают неизвестный
prerelease, обнаружить его через latest невозможно. Принудительной авторизации
и обхода TLS нет. Точный источник непостоянства ответов GitHub не доказан.
