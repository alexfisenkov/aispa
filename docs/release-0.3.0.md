# AISpa 0.3.0

## Документы проекта

- Подхват INTERVIEW, INTENT, SPEC, PLAN, INDEX и русских аналогов; адресная
  привязка документов под любыми безопасными Markdown-именами.
- Сохранение выбранного замысла между запусками без переноса старых задач и PASS.
- Понятная карта оригиналов и служебных файлов в существующем INDEX AISpa.
- Отказ от неоднозначного/устаревшего источника; перечитывание и перепривязка
  без дополнительного этапа утверждения владельцем.
- При отсутствии замысла агент готовит один документ по проекту и брифу;
  движок не придумывает его из последней задачи и не создаёт пять шаблонных дублей.

## Среды агентов

К Codex, Claude Code и Cursor добавлены OpenClaw, Gemini CLI и Antigravity
app/IDE: native paths, правила проекта, регистрация участников и проверки
источников. Установщик не принимает старый пакет для неподдерживаемой среды.

Проверка обновлений умеет использовать системный CA, когда Python не нашёл
собственный bundle. TLS остаётся проверяемым; настройки пользователя не меняются.

## Совместимость

Политика запуска закрепляется на init. Старые активные прогоны продолжаются
своим runtime; завершённая 0.2.0 доступна как история, без переноса старых PASS.
После установки откройте новый чат агента. Роли и режимы проверки сохраняют
действующий контракт; наличие папки навыка не доказывает доступность инструментов.

Новые полные модельные прогоны и замеры экономии этой итерацией не проводились.
Инженерные тесты, native discovery и публикация ресурсов описаны отдельно в
[validation-0.3.0.md](validation-0.3.0.md).

## Проверки при публикации

По решению владельца выпуск доступен для тестирования на Mac до завершения
Windows CI. Локальные инженерные проверки macOS пройдены; статус матрицы
проверяется отдельно по ссылке в протоколе. Полных модельных прогонов нет.
