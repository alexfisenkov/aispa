# Проверки AISpa 0.3.5

23.10.2026 владелец утвердил компактный дашборд и разрешил merge, релиз
и обновление локальных установок агентов. Предыдущий запрет выпуска макета
отменён этим поручением. Новых полных модельных прогонов нет.

## Принятый интерфейс

[Макет и browser evidence](dashboard-compact-preview.md): 82 Node-теста,
3 Python-проверки, нативный просмотр desktop/mobile, dark/EN, pause/stale/accepted;
[предыдущая адресная CI](https://github.com/alexfisenkov/aispa/actions/runs/39839191200).
В релизной подготовке HTML меняет только демонстрационный номер версии.
Старые скриншоты сохраняют происхождение: это одобренный макет, не снимок выпуска.

## Подготовка выпуска

Версия 0.3.5 согласована во входном файле, движке и demo. В явные списки
read-only совместимости добавлены 0.3.3 и 0.3.4: следующий VERSION не должен
лишать старый прогон просмотра и завершённую историю handoff. Обычный writer
по-прежнему отклоняет несовпадающую версию; активный handoff запрещён.

Локально: 82 Node-теста и 73 Python-проверки PASS. Включены обновление,
первая установка, exact Git baseline preview, просмотр прошлых patch-версий,
запрет записи совместимым reader и отказ на повреждённом/неподдержанном состоянии.
Неизменность принятого HTML подтверждена сравнением с `a3d2647…` после замены
только demo-номера 0.3.4 на 0.3.5.
