# Проверки AISpa 0.3.0

Выпуск разрешён владельцем по пройденным проверкам macOS до завершения Windows CI.
Это не подтверждение Windows. Публикация ресурсов и установка фиксируются после read-back.

## Локальные проверки

- 214 адресных тестов macOS — PASS, 375.449 с, включая полный сценарий CLI
  и проверки режимов fast/max/promote/switch на синтетических отчётах.
- После замечаний: 61 адресный тест — PASS; затем 32 — PASS.
- Последний preflight: 26 тестов — PASS, 58.022 с: неверный slug/активный
  run не меняют .gitignore; отменённый ignore и tracked .aispa отказывают до
  приватных снимков; полный CLI проходит.
- Два реальных init в синтетической папке: замысел сохранён, прежний scope
  пуст, пять исходных документов не изменились, INDEX ведёт к оригиналам.
- Проверка обновлений без SSL_CERT_FILE: до исправления offline; после — current.

Сводка локальных квитанций: [local-verification.json](pilots/0.3.0/local-verification.json).

## Независимый разбор

Техника и риски нашли вложенный ignored source, проверку прежних снимков,
credential guards и предохранители init. Подтверждённое исправлено; последние
предохранители после второго круга проверены основным агентом, третьего круга нет.
Контроль доказательств — OK для реализации и карты; это не подтверждение доставки.
Обычные контакты в разрешённых локальных документах не запрещаются; секреты
не копируются, снимки остаются в исключённой из Git .aispa.

будущего проекта и реальные полномочия всех конфигураций host этим не доказаны.
