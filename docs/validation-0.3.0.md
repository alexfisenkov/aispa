credential guards и предохранители init. Подтверждённое исправлено; последние

[Проверка установок](pilots/0.3.0/installation-verification.json).

новый запуск. Рабочее дерево не копировалось поверх установленного навыка.

## Последующий результат Windows

Матрица завершилась: Linux/macOS PASS; обе Windows (3.11/3.13) — шесть ошибок
из 529 тестов. Все в test_project_documents_cli: helper читал UTF-8 stdout
системным cp1252 и падал до проверок. Это не подтверждение сбоя движка, но
шесть сценариев не прошли приёмку Windows. Исправление явного encoding=utf-8
и повтор этих сценариев включены в 0.3.1; прочие 523 теста без ошибок.
