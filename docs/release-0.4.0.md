# AISpa 0.4.0

Смешанные способы проверки задачи: автоматические тесты, браузерные
наблюдения и проверки процесса. Подготовлено 24.10.2026 по issue №12;
факт выпуска и доставки — [протокол](validation-0.4.0.md).

- `mode: mixed` связывает каждый исходный критерий с одним или несколькими
  способами проверки. Критерии не сокращаются и не переносятся молча.
- Автоматическая группа сохраняет реальные RED/GREEN проверки.
  Браузерная и процессная группы получают отдельные наблюдения с привязкой
  к попытке, кандидату, контракту и контрольным суммам приложений.
- Все существующие роли оценивают каждый заявленный способ. Непроверенная
  группа не превращается в общий PASS. Дополнительного интервью или нового
  обязательного агента этот режим не вводит.
- История test-intent сохраняется; понижение способа ради обхода проверки,
  стирание попытки и обход начатой критики запрещены.
- Формы, пакеты контекста, инструкции и детали задач в дашборде показывают
  три вида проверок. Пустые формы не являются свидетельствами.
- Прежние режимы работают по прежним контрактам; общая независимая приёмка
  по брифу и чистому клону сохраняется.

Новая политика включается при новом init. Обновление установленного навыка
не меняет закреплённые runtime активных проектов. Полные модельные проекты
для этого выпуска не запускались.
