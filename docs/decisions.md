# Решения AISpa

## Принято 19.10.2026

- Имя проекта — AISpa, репозитория и будущей команды — `aispa`.
- Репозиторий публичный, разработка и проверки прослеживаются в GitHub.
- Реализация, тексты и интерфейс создаются самостоятельно.
- Рабочая версия — `0.1.0-alpha.1`; стабильный выпуск требует отдельного решения.
- Дизайн и сокращение дашборда определяет владелец позже.
- Исходный бриф и выполненная задача должны быть связаны проверяемыми данными.
- Поведение продукта согласуется в интервью перед реализацией спорных решений.

## Открыто: первый раунд интервью

1. Нужны ли интервью и подтверждение понимания перед каждым проектом.
2. Как продолжать работу при препятствии: независимые части или полный стоп.
3. Какие доказательства обязательны для статуса «готово».

Дополнительно предстоит определить частоту сверки с брифом, границы
самостоятельных улучшений, правила применения новых требований и условия
распространения навыка. Отсутствие ответа не считается согласованием.
