### Обновление 0.1.0 → 0.2.0 и откат

В отдельной папке по `--tag v0.1.0` поставлена опубликованная 0.1.0 (78 файлов,
`--version` = 0.1.0); её снимок (SHA-256 и режимы всех файлов) сохранён.

- `update-check` вернул `available` (0.2.0, installAllowed true);
- `update-prepare` подготовил кандидата рядом с пакетом: added 2, changed 42,
  removed 0, unchanged 36, `candidateDigest` совпал с digest первой установки 0.2.0;
- `update-apply --confirm`: установлено 80 файлов, `--version` = 0.2.0, полное
  совпадение с manifest, `update-check` = `current`; прежняя версия сохранена
  в `.aispa-backup-<id>` (`backupDigest` равен `expectedCurrentDigest` prepare);
- `update-rollback --backup … --confirm`: статус `rolled_back`,
  `--version` = 0.1.0, 78 файлов; снимок байтов и режимов после отката
  идентичен снимку до обновления. Откатываемая 0.2.0 осталась в каталоге
  резервной копии (`replaced/package`).

Первая установка 0.2.0 в соседней папке при этом осталась побайтно равной
manifest. Запускался обычный `python3 tools/aispa.py` без `-I`: этот скрипт
подключает соседние модули по своему каталогу, как и в README.

Глобальные установки не менялись. Эта проверка доставки выполнена на Mac;
нативная Windows подтверждена отдельной CI движка и установщика, не живой
установкой скачанного Release на пользовательский Windows-компьютер.

## Не проверяется этой итерацией

- Новые полные модельные прогоны и измерение экономии токенов и качества
  lean-контроля и режимов проверки: не проводятся по решению владельца.
- Все пользовательские конфигурации Codex, Claude Code, Cursor и Windows-host:
  локальные тесты и CI не заменяют их отдельную приёмку.
- Изменение глобальных установок: не выполняется. Старые активные runtime и
  исторические отчёты не переписываются.
- Переход с alpha-версий на 0.2.0 в этой проверке не повторялся (проверен 0.1.0 → 0.2.0).

Число ролей, байты контекста и `verified_completion` не являются измерением
токенов, модельным PASS или итоговой приёмкой проекта. Сохраняющиеся ограничения
и пользовательская матрица — [testing.md](testing.md).
