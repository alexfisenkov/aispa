## Изменения

Подготовительные формы brief-extract/review/map, scenarios и interfaces
можно записать через --write и передать адрес, не печатая весь JSON.
brief-source --write сохраняет только полный исходный материал; результаты
независимых разборов в него не попадают. brief-map-context --write имеет
прежние требования к двум разборам и актуальности исходников.

context --kind task --task … --role … --write --with-template выдаёт
ссылки на карточку, контекст и редактируемую форму. Проверяются действительное
назначение, стадия, текущая проверка worker и допустимость critic2 после
ремонта. Форма не создаёт PASS и не сдаётся автоматически. Отдельные команды
и прежний вывод сохранены для совместимости. Пути форм абсолютные и
относительные, поэтому --root работает при другом cwd участника.
