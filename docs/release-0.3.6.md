# AISpa 0.3.6

Исправление длинных исходных цитат и адресный ремонт заблокированного
прогона 0.3.5. Подготовлено 24.10.2026; факт публикации и результаты проверок —
[протокол](validation-0.3.6.md).

- Сценарии принимают полную зарегистрированную цитату длиннее 1600 символов,
  включая источник родительского требования у дополнений.
- Сохраняются точное совпадение цитаты, проверка неизменного брифа, актуальный
  basis и общий предел отчёта 512000 символов. Другие текстовые лимиты не сняты.
- Отдельный инструмент ремонта исправляет только известный дефект в точной
  копии опубликованного 0.3.5. Он требует подтверждения, сохраняет старый
  runtime и дописывает историю. Это не автоматическая миграция всех проектов.
- В контракте интерфейсов явно указан объект ссылки `{file, sha256}`;
  у отдельной команды материала владельца остаётся `{path, sha256}`.
- Просмотр и read-only handoff сохраняют совместимость с 0.3.5.

Новые проекты используют 0.3.6 после установки опубликованного обновления.
Начатому прогону смена глобального навыка сама по себе исправление не применит:
см. [адресный ремонт](runtime-repair.md). Полные модельные проекты для этого
выпуска не запускались.
