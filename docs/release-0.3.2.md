# AISpa 0.3.2

- Вопросы закрываются после первого брифа и не возвращаются при его дополнении.
  Агент сообщает, что можно отойти, сохраняет решения и возвращает их в финале.
- Исправлено падение status после второй завершённой задачи: неизвестное время
  pending-задачи больше не ломает расчёт; активное время не считается дважды.
- Проверки показывают отдельные состояния, требования — фактический ход работ,
  волны — собственную сверку. Завершённая задача не приравнивается к приёмке проекта.
- Этапы перенесены вверх, время собрано в два показателя, задачи разворачивают
  требования и критерии. Цвета дополнены текстом; раскрытие переживает polling.
- Ориентир времени появляется по плану до первых измерений, затем уточняется.
- Совместимый refresh-view обновляет только панель старого активного проекта,
  сохраняя закреплённый движок и журнал. Новая автономия требует нового init.
- Обновлённая служба не переиспользует устаревший run/runtime/HTML; повторные
  хеши кода в одном запросе не пересчитываются. Между запросами данные проверяются снова.
- Исправлено чтение UTF-8 артефакта в Windows-тесте предыдущей версии.

Новых полных модельных прогонов нет. [Проверки и ограничения](validation-0.3.2.md).
