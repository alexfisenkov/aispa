# Учебный план — воспроизводимый пример

Пример создан в нативном пилоте AISpa alpha.6. Источники истины: `docs/brief.md`,
`docs/spec.md`, README и проверяемый код. Данные в examples/tasks.csv синтетические.

Python 3.11+, только стандартная библиотека. Домен: studyplan/domain.py;
аргументы и вывод: studyplan/__main__.py; проверки: tests/. Не дублировать
алгоритм планирования в CLI. Сохранять входной CSV и старый output при ошибках.

Из этой папки: `python3 -m unittest discover -s tests -v` и
`python3 -m studyplan examples/tasks.csv --budget 90`.
На Windows использовать `python` или `py -3` вместо python3.

Известное необязательное улучшение: сообщение о синтаксически повреждённом CSV
с незакрытой кавычкой не содержит номера строки. Ошибка отклоняется; эту
диагностику нельзя описывать как уже улучшенную. Частная история агентов и
тестовые журналы пилота в пример не включены.
