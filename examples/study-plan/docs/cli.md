# Командная строка и файлы

Документ нужен при реализации входной команды и вывода результата. Запуск: python3 -m studyplan examples/tasks.csv --budget 90. Необязательный --output plan.json сохраняет тот же JSON в файл. Без --output JSON идёт в stdout, без служебных сообщений рядом.

При ошибке входа команда возвращает ненулевой код и понятное сообщение в stderr. Python traceback в обычном сообщении об ошибке не нужен. Существующий выходной файл не должен измениться при ошибке чтения или валидации. Если новый путь указан при неверном входе, файл не создаётся. CSV-источник никогда не переписывается, в том числе если пользователь укажет его как --output.

Успешная запись файла может использовать временный файл рядом с ним и замену после полной подготовки JSON. Каталоги автоматически не создаются: неверный родительский путь получает понятную ошибку. Защита от одновременного внешнего редактирования не объявляется. Сетевой режим, интерактивное интервью и установка зависимостей не нужны.

Пути с пробелами передаются как один аргумент. На Windows используется python либо py -3. Печать результата должна работать с кириллицей и эмодзи, когда stdout перенаправлен в файл. В JSON нет ANSI-цветов. Справка --help объясняет оба параметра и единицу бюджета — минуты.
