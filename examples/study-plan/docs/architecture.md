# Архитектура

Документ нужен при изменении границ модулей и восстановлении контекста. studyplan/domain.py читает CSV через явную функцию и рассчитывает план чистой функцией. Доменные ошибки выражаются исключением с понятным текстом, а не завершением процесса внутри библиотеки.

studyplan/__main__.py принимает аргументы, вызывает домен, сериализует JSON и управляет stdout/stderr/выходным файлом. CLI не дублирует правила сортировки и валидации. Небольшой __init__.py только обозначает пакет. tests/test_domain.py и tests/test_cli.py проверяют разные уровни; полный набор используется после каждой волны.

В проекте нет web-сервера, хранения состояния, авторизации, аналитики пользователей или базы данных. Результат полностью определяется файлами входа и аргументами команды. Добавление GUI или сетевой синхронизации выходит за текущий бриф.

Примеры задач синтетические и безопасны для публикации. README содержит команды для проверки и запуска. Внутренняя история AISpa отделена в .aispa и не становится частью поставки продукта. Конкретные публичные API домена определяет исполнитель, сохраняя эту границу и требования.
