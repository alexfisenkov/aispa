# Учебный план: тестовый бриф

Синтетический пример выбран координатором по прямому поручению владельца выбрать небольшой проект для испытания AISpa. Это не запись отдельной речи владельца и не работа с настоящими учениками.

Читай CSV с точным заголовком title,minutes,priority в UTF-8 или UTF-8 BOM; заголовок без строк означает пустой список.

Проверяй всю таблицу: title непустой после trim, minutes — целое от 1 до 480, priority — целое от 1 до 3; ошибочный ввод отклоняется без частичного плана.

Планируй по убыванию priority; при равенстве сохраняй исходный порядок строк. Не поместившуюся задачу пропускай и продолжай выбирать следующие.

Бюджет — целое от 0 до 1440 минут. Верни planned, deferred, total_minutes и budget; deferred сохраняет исходный порядок, сумма точна, результат детерминирован, входные данные не меняются.

Команда python3 -m studyplan examples/tasks.csv --budget 90 выводит JSON в stdout; необязательный --output сохраняет тот же JSON в файл. Кириллица и эмодзи сохраняются.

При неверном вводе возвращай ненулевой код и понятную ошибку в stderr: не создавай новый выходной файл и не меняй существующий. Исходный CSV нельзя переписать, даже если он передан как --output.

Добавь реальные unittest-проверки и README с рабочими командами запуска и проверки. Пример tasks.csv должен запускаться из чистого Git-клона без дополнительных файлов.

Работай офлайн на Python 3.11+ только стандартной библиотекой; сеть, платежи, аккаунты, сторонние зависимости и данные учеников не нужны.
