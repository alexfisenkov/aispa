# Переносимость

Документ нужен при выпуске и проверке окружения. Целевые системы — macOS, Linux и нативная Windows с Python 3.11+. Продукт использует pathlib и стандартные модули csv/json/argparse. Shell-скрипт активации окружения не нужен.

Текстовые файлы имеют UTF-8; CSV допускает BOM. При чтении CSV newline обрабатывается библиотекой csv, поэтому CRLF и LF не должны создавать лишние строки. Выходной JSON не зависит от локали. Не полагаться на существование python3 в Windows, системного bash или команды cat.

Переносимость исходного кода не равна проверке всех ОС. В текущем модельном пилоте фактически используется macOS. Нативную Windows для движка AISpa подтверждает отдельная опубликованная CI, а продукт этого пилота проверяется по фактически выполненным сценариям.

Пути могут содержать пробелы и кириллицу. Символические ссылки и специальные файловые системы не являются отдельным обещанием продукта. В README нужно дать команды для доступного Python и не рекомендовать отключение TLS или изменение глобальных разрешений ради запуска.
