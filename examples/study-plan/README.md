# Учебный план

Локальная программа составляет план учебного дня из синтетических CSV-задач. Нужен Python 3.11+; используются только модули стандартной библиотеки. Интернет, учётные записи и установка пакетов не нужны.

Из корня проекта запустите пример:

```sh
python3 -m studyplan examples/tasks.csv --budget 90
```

На Windows используйте `python -m studyplan examples/tasks.csv --budget 90` или `py -3 -m studyplan examples/tasks.csv --budget 90`. Путь с пробелами заключайте в кавычки. Бюджет задаётся целым числом минут от 0 до 1440.

Пример напечатает JSON в stdout:

```json
{
  "planned": [
    {"title": "Практика", "minutes": 45, "priority": 3},
    {"title": "Чтение", "minutes": 25, "priority": 2},
    {"title": "Разбор", "minutes": 20, "priority": 2}
  ],
  "deferred": [
    {"title": "Повторение 🙂", "minutes": 10, "priority": 1}
  ],
  "total_minutes": 90,
  "budget": 90
}
```

Пробелы в фактическом выводе могут отличаться от компактного примера выше. Больший `priority` выбирается раньше, а при равенстве сохраняется порядок CSV. Задача, которая не помещается, пропускается без остановки отбора.

Чтобы сохранить тот же JSON в UTF-8 файле вместо stdout:

```sh
python3 -m studyplan examples/tasks.csv --budget 90 --output plan.json
```

Входной CSV должен иметь точный заголовок `title,minutes,priority` и кодировку UTF-8 (BOM допустим). `title` не может быть пустым после удаления пробелов по краям; `minutes` — целое от 1 до 480; `priority` — целое от 1 до 3. Заголовок без задач допустим. Ошибка в любой строке отменяет весь результат: команда выводит сообщение в stderr, возвращает ненулевой код и не создаёт или не меняет выходной файл. Исходный CSV нельзя указать как `--output`.

Проверка из корня проекта:

```sh
python3 -m unittest discover -s tests -v
```

На Windows замените `python3` на `python` или `py -3`. Тесты запускают CLI через текущий Python, проверяют Unicode, пример, ошибки и сохранность входных и выходных файлов. Проверки на другой ОС выполняются отдельно.
