# AISpa

**0.1.0-alpha.1 · экспериментальная версия · для испытаний**

AISpa — навык для разработки проекта по исходному брифу. Его основа —
прослеживаемая связь между словами заказчика, требованиями, задачами и
проверенным результатом. Отчёт о проделанной работе сам по себе не является
подтверждением выполнения требования.

Собственный движок и инструкции реализуют правила, согласованные в интервью
с владельцем. Стабильный выпуск и готовность комплекта для учеников ещё не
объявлены. Дизайн дашборда будет изменён отдельно.

## Как работает

- В начале пользователь выбирает полный автомат, только важные вопросы или
  подробное интервью. Вопросы заканчиваются на этапе брифа.
- До разработки фиксируется обязательное ядро. Агент принимает дальнейшие
  решения сам и перечисляет их в финале.
- Перед задачей и после неё проверяются её требования и общие ограничения;
  после каждой волны — весь бриф.
- Изменение брифа, плана или кода делает относящиеся к ним проверки устаревшими.
  Пустой план, неполный отчёт или отсутствие доказательства блокируют переход.
- Если ядро принято, второстепенные недоделки допускают сдачу с пометкой
  «основная часть готова, есть остатки». Они сохраняются в учёте.
- Полезные добавления разрешены отдельно от исходных требований. Отмена
  или перенос требования требуют записанного решения владельца.

## Попробовать альфу

Пакет — [skills/aispa](skills/aispa), вход — [SKILL.md](skills/aispa/SKILL.md).
Для теста скопируйте **всю папку** `aispa` в свободный каталог навыков:

| Среда | Каталог в тестовом проекте | Запуск |
|---|---|---|
| Codex | `.agents/skills/aispa/` | `$aispa` |
| Claude Code | `.claude/skills/aispa/` | `/aispa` |
| Cursor | `.cursor/skills/aispa/` | `/aispa` |

Если одноимённый навык уже есть, сначала сохраните его; не объединяйте версии
поверх друг друга. Подробности и граница подтверждённой совместимости —
[runtimes.md](skills/aispa/references/runtimes.md).

Начните с небольшого проекта без реальных платежей и пользовательских данных.
Сохранённые брифы и доказательства остаются в локальном `.aispa/`, который
исключён из Git. Каждый прогон сохраняет собственную копию движка: обновление
установленного пакета не меняет уже начатую работу.

## Что подтверждено

Проверки выполняют собственный движок на синтетических данных: сохранение
истории, отказ на повреждении, отрицательные сценарии переходов, приёмку
ядра с остатками, устаревание доказательств и полный проход CLI. Локальный
HTTP-тест проверяет выдачу дашборда и состояния.

Полные LLM-прогоны в Codex, Claude Code и Cursor ещё предстоят. Успешные
тесты Python не доказывают, что любая модель правильно поймёт любой бриф.
Это ключевая часть испытаний до 1.0. План — [docs/testing.md](docs/testing.md).

Временный экран: [dashboard.html](skills/aispa/assets/dashboard.html).
Схема его данных: [docs/dashboard.md](docs/dashboard.md). Виджет только
отображает результат; право назвать работу готовой определяет движок.

## Разработка

Python 3.11+ и Git. Сторонние Python-библиотеки не требуются.

```bash
python3 -m unittest discover -s tests -v
```

GitHub Actions запускается вручную для согласованного набора изменений.
Публичность репозитория не означает выпуск стабильного продукта.

Структура: `skills/aispa/` — пакет навыка, `tests/` — проверки,
`docs/` — решения и история изменений. Текущие границы работы — [AGENTS.md](AGENTS.md).
