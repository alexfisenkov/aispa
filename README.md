# AISpa

**0.1.0-alpha.1 · разработка · не готово для рабочего использования**

AISpa — навык для разработки проекта по исходному брифу. Его основа —
прослеживаемая связь между словами заказчика, требованиями, задачами и
проверенным результатом. Отчёт о проделанной работе сам по себе не является
подтверждением выполнения требования.

Сейчас создаётся собственная реализация. Поведение уточняется в интервью с
владельцем. Первая стабильная версия и выпуск для учеников ещё не объявлены.

## Состояние

- Создан отдельный проект и начата реализация журнала изменений.
- Проверяются неизменность исходных данных, целостность истории и привязка
  проверок к конкретному состоянию проекта.
- Правила интервью, работы с блокерами и финальной приёмки согласуются.
- Внешний вид дашборда будет разработан отдельно. Сначала определяется
  достоверность показываемых данных.

## Разработка

Python 3.11+ и Git. Сторонние Python-библиотеки не требуются.

```bash
python3 -m unittest discover -s tests -v
```

GitHub Actions запускается вручную для согласованного набора изменений.
Публичность репозитория не означает выпуск стабильного продукта.

Структура: `skills/aispa/` — пакет навыка, `tests/` — проверки,
`docs/` — решения и история изменений. Текущие границы работы — [AGENTS.md](AGENTS.md).

Условия распространения и использования будут определены до выпуска.
