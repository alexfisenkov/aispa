# AISpa 1.0

AISpa собирает приложение, сайт, бота или большую доработку по вашему
рассказу, до готового результата. Вы описываете, что нужно, своими словами.
AISpa записывает каждое ваше требование дословно, задаёт вопросы только там,
где бриф оставил развилку, строит проект шаг за шагом отдельными исполнителями
и в конце проверяет итог по вашим же словам, а не по своему пересказу. Всё
время рядом открыта панель: что уже сделано, что идёт сейчас и сколько
примерно осталось.

## Когда AISpa нужна, а когда хватит обычного чата

**Нужна**, когда вы диктуете, что построить, и ждёте готовое, не читая
описаний и кода: бот с ролями и базой, сайт с сервером, приложение,
автоматизация из нескольких связанных частей. Работа большая и идёт заметную
часть лимита.

**Не нужна**, когда вы пишете код вместе с агентом строка за строкой, когда
нужна маленькая правка в одном файле или разовый вопрос по коду: обычным чатом
это быстрее и дешевле. Идею, которая больше одного проекта и в которой пока
неясна цель, сначала уточните. Тексты, посты, картинки и видео AISpa не
делает.

## Установка

Нужны Python 3.11 или новее, Git и агент с терминалом: Claude Code или Codex.
Аккаунт и токен GitHub не нужны. Самый простой путь: попросить своего агента
установить AISpa из последнего выпуска. Подробно, со всеми средами и папками:
[установка](docs/install.md). Как обновить: [обновление](docs/updates.md).
На Windows: [нативная Windows](docs/windows.md).

## Запуск

- **Claude Code:** откройте папку проекта и напишите `/aispa`, а после него
  идею проекта или путь к файлу с брифом.
- **Codex:** напишите `$aispa` и идею проекта.

AISpa запускается только вашей командой, сама она не включается. Вызов без
задачи продолжает прерванную сборку: она читает папку `.aispa-work/` проекта и
идёт дальше с того места, где остановилась, в том числе в новом чате.

## Какую модель выбрать для главного чата

Советуем Opus 5.5 в Claude Code и Sol 6.1 в Codex: высокое усилие (high) на
брифе и плане, дальше среднее (medium). Это совет, а не требование.
Исполнителей и проверяющих AISpa назначает сама, по таблице ролей в
[`skills/aispa/SKILL.md`](skills/aispa/SKILL.md).

## Что получится в проекте

Рабочая папка `.aispa-work/` лежит в вашем проекте и коммитится вместе с ним:
бриф дословно, список требований, описание, шаги, итоговый отчёт и
`PROGRESS.md` с тем, что осталось. Секреты (ключи, пароли) AISpa никогда не
просит и не записывает: только имена переменных, значения вы кладёте в `.env`
сами.
