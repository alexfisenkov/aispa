# Проверка обновления, установка и откат

Открывай при первом действии явного вызова и когда человек просит обновить
или вернуть прежнюю версию. Audit-only (`assess`) и чтение `faq` этот путь не
запускают.

## Первое действие

Для обычной разработки сразу выполни
`python3 "<skillDir>/tools/aispa.py" update-check` из открытого установленного
пакета. На Windows выбери реально доступный Python 3.11+ (`python` или
`py -3`); launcher и его аргументы передавай отдельно. Не повторяй
отсутствующий `python3` либо Store alias. ОС и native runtime различны.
Поддерживаемые ID: `codex`, `claude-code`, `cursor`, `openclaw`, `gemini`,
`antigravity`. Нативные роли, права и доступные измерения сначала проверь по
[адаптерам сред](native-agents.md); название модели не определяет runtime.
Не подменяй отсутствующие независимые контексты именами ролей.

## Источник и выбор человека

Источник обновления — опубликованный GitHub Release `alexfisenkov/aispa`:
ветка main, tag и draft не считаются выпуском. Аккаунт, токен, `gh` и PAT не
нужны. Если есть новый выпуск с `installAllowed: true`, выполни
`update-prepare`, покажи текущую и новую версии, ссылку на Release, commit и
изменённые файлы. Предложи выбор «Установить обновление» / «Продолжить с
текущей версией». Только после явного выбора установки:
`update-apply --candidate <candidateId> --confirm`, затем перечитай
установленный SKILL.md. `--confirm` фиксирует уже полученный выбор, а не
заменяет его. Без выбора пакет не меняется.

При `offline`, `no_release`, `current`, `invalid_release`, ошибке подготовки или
защищённом каталоге продолжай текущим пакетом и кратко назови результат.
`offline` с `reason: "github_rate_limit"` значит, что GitHub временно ограничил
запросы без входа: передай человеку `message` из ответа (аккаунт и токен не
нужны, попробовать позже) и продолжай. Активный прогон остаётся на закреплённом
runtime; не устанавливай main вместо Release.

## Агенты Claude Code

Для пакета в `*/.claude/skills/aispa` установка и обновление кладут файлы
агентов `aispa-*.md` в соседний `.claude/agents/` вместе с резервной копией
пакета. Изменённый пользователем или чужой файл с тем же именем не
перезаписывается и называется в квитанции (`agents.skipped`). Новые агенты
видны только в новом сеансе Claude Code; до него действует запасной ход из
[адаптеров сред](native-agents.md).

## Откат

`update-apply` возвращает `backupId`. Вернуть прежнюю версию можно только по
явной просьбе человека: `update-rollback --backup <backupId> --confirm`.
Откат отказывает, если резервная копия изменена или установленный пакет
меняли после обновления; тогда назови причину и ничего не правь руками.
Квитанция `agentsRollback` перечисляет возвращённые и пропущенные файлы
агентов. После отката перечитай установленный SKILL.md.

Подробности установки и путей сред: [процесс](process.md),
[среды](runtimes.md).
