# Живые этапы и время

Панель показывает сохранённые события. Назначение участника не доказывает,
что он уже реализует задачу; сохранённый отчёт не доказывает, когда он начал.
Не подставляй выдуманные часы и не рисуй PASS ради полноты экрана.

## Задача

Перед передачей задачи: свежий worker context → start с его basis → назначение
нативного участника → работа. Если участник создан раньше назначения, он ждёт
передачи контекста; нельзя писать код до start. Если start уже есть, повтор не
нужен. Координатор проверяет, что start прошёл, и только затем передаёт работу.
Assign без start виден как «Исполнитель назначен / Старт реализации не отмечен».

Submit, critic, repair и complete меняют фазу автоматически по действующей
политике. Не добавляй второй круг после первого PASS. Длительность фазы —
интервал нахождения на этом этапе, с отмеченными паузами; она включает ожидание
участника и не означает измеренное время CPU/модели. Роль и среда показываются
только из сохранённого назначения текущей попытки.

## Подготовка и сдача

Перед работой вызывай `progress begin <phase>`, после неё — `progress end`.
Один begin на смену этапа, не на каждый файл или сообщение. Повтор того же
begin не обнуляет часы. Смена этапа закрывает прошлый интервал. После паузы
часы продолжаются, явное ожидание владельца не считается активной работой.
Если нативная сессия оборвалась, оставшийся интервал не доказывает продолжение
работы агента: при возвращении проверь состояние и отметь pause/end при необходимости.

| Работа | phase |
|---|---|
| Изучение замысла и вариантов | idea |
| Интервью, разбор брифа и требования | brief |
| Изучение проекта | discovery |
| Спецификация | spec |
| Сверка покрытия | coverage |
| Планирование задач | plan |
| Подготовка команды и карточек | team |
| Общая сверка после волны | wave |
| Обзор всей версии | integration |
| Документы передачи | handoff |
| Подготовка чистого клона | cleanroom |
| Независимая слепая проверка | blind |
| Итоговая сверка с брифом | acceptance |
| Запись знаний и памяти | knowledge |

Start задачи закрывает общий подготовительный интервал. Отчёт соответствующей
фазы также завершает его; неизвестный промежуточный шаг закрывай progress end.
Verify/clean-verify показываются сами на время выполняемой команды, включая
таймер проверки чистого клона. Незнакомый тип активности не скрывает текущий этап.

Панель опрашивает журнал каждые пять секунд; таймеры обновляются раз в секунду.
При обрыве связи часы замораживаются, архив показывает только сохранённое.
Приёмка, актуальность доказательств и приблизительный срок остаются отдельными.
В старых прогонах без progress доступны прежние этапы и события; отсутствующее
начало фазы помечается как неизвестное, а не восстанавливается предположением.
