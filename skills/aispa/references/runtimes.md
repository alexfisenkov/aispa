# Codex, Claude Code, Cursor

Во всех трёх средах используется одна папка `aispa` целиком. Механизм работы
с требованиями одинаков; вызовы инструментов берутся из доступного реестра
конкретной сессии. Не выдумывай имена инструментов и не считай список файлов
подтверждением запуска агентов.

| Среда | Каталог для проектной установки | Явный вызов |
|---|---|---|
| Codex | `.agents/skills/aispa/` | `$aispa` или выбор через меню навыков |
| Claude Code | `.claude/skills/aispa/` | `/aispa` |
| Cursor | `.cursor/skills/aispa/` | `/aispa` |

Codex: `agents/openai.yaml` отключает неявный запуск. Используй доступный
инструмент опроса для выбора режима. Независимому проверяющему передавай
ограниченный контекст, без наследования истории исполнения; параметры роли
и модели подчиняются правилам проекта.

Claude Code: `disable-model-invocation` оставляет запуск явным. Для исполнителей
и проверяющих используй доступных нативных субагентов с раздельными заданиями.
Не копируй правила чужого рантайма в настройки Claude Code.

Cursor: тот же явный запуск и стандартный формат SKILL.md. Поддержка агентов,
опросов, shell и браузера зависит от выбранного режима и окружения Cursor;
проверь её перед обещанием независимой приёмки. При отсутствии опроса покажи
три варианта текстом; при отсутствии независимого контекста отметь ограничение.

Python 3.11+ и Git нужны для движка. Установку требуемых продукту зависимостей,
модели и ресурсные лимиты определяют окружение и правила проекта. AISpa
не содержит ключей API и не обращается к модельным провайдерам самостоятельно.

Формат размещения сверялся по официальным источникам 19.10.2026:
[Codex](https://learn.chatgpt.com/docs/build-skills),
[Claude Code](https://code.claude.com/docs/en/skills),
[Cursor](https://cursor.com/docs/skills).
Это проверка документированного формата. Полные модельные прогоны AISpa
в этих трёх приложениях пока не подтверждены; они входят в испытания альфы.
